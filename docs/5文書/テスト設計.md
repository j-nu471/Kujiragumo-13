## 実行方法
- 単体・結合：手で実行する（`http://localhost:8000/docs` の画面、またはブラウザ）。pytest は今回使わない。結果（画面のスクショ・返ってきた JSON）を `evidence/` に保存する
- **テストはそのコードを実装した人が書いて実行し、結果を`evidence/`に残してPRに付ける**。いでっちはPRレビューで証拠を評価する
- システム・受入：手元で画面と API を両方起動して手動で行い、スクリーンショットを `evidence/` に保存する
- スクショに DB の接続先・パスワードが写っていないか確かめてから保存する（リポジトリは Public）
